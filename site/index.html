<p>Interpretable Machine Learning for Mortality Risk Stratification in Hantavirus Infection: A Global Study Across Hemorrhagic Fever with Renal Syndrome and Hantavirus Cardiopulmonary Syndrome</p>

Background: Hantavirus infection is rare but potentially fatal, requiring early risk identification (A1). Methods: Retrospective analysis of 10,000 global cases (mortality outcome) using logistic regression, random forest, and XGBoost with extensive preprocessing; cohort included 8,938 recoveries and 1,062 deaths (A4,A5,A7,A9). Results: Logistic regression had ROC‑AUC 0.858, recall 0.741, precision 0.321; gradient boosting similar AUC 0.857 with precision 0.511; random forest low recall 0.085; key predictors were severity, syndrome type, viral load, age, geography (A10,A11,A12,A14). Contribution: Shows interpretable ML can stratify hantavirus mortality risk, prioritizing sensitivity and transparency, and provides a framework for validation (A15,A16). Limitations: No explicit limitations reported.
